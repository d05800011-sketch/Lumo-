# Lumo

Простой веб-мессенджер с сообщениями в реальном времени. Работает бесплатно: фронтенд на чистом HTML/JS (без сборки), бэкенд на [Supabase](https://supabase.com), хостинг на GitHub Pages.

## Возможности

- Регистрация и вход по email и паролю
- Личные чаты, группы и каналы (в канал пишут только администраторы)
- Поиск каналов по названию и адресу, вступление в один клик
- Аватарки у пользователей, групп и каналов (фото сжимается прямо в браузере)
- Счётчики непрочитанных, звук и системные уведомления, режим «Без звука» для чата
- Установка на телефон как приложение (PWA)
- Безопасность на уровне базы (Row Level Security): читать чат могут только его участники

## Запуск

1. Создайте проект Supabase на [supabase.com](https://supabase.com) (бесплатный тариф).
2. В *SQL Editor* выполните по очереди:
   1. `schema.sql` (основа)
   2. `migration_v2.sql` (группы, каналы, аватарки, непрочитанные)

   На вопрос про RLS отвечайте **Run and enable RLS**.
3. *Project Settings → API*: скопируйте **Project URL** (без `/rest/v1/`) и публичный ключ (**publishable** или **anon**, но не secret).
4. Создайте `config.js` по образцу `config.example.js` и впишите значения.
5. Локально: `python3 -m http.server 8000`, затем http://localhost:8000. Или опубликуйте на GitHub Pages.

> Чтобы не ждать письмо при регистрации, отключите *Authentication → Sign In / Providers → Email → Confirm email*.

## Уведомления

Работают, пока Lumo открыт (в том числе в свёрнутой вкладке): звук, счётчик в заголовке вкладки и системное уведомление. Включаются в профиле.

- **iPhone:** сначала добавьте Lumo на экран «Домой» (Поделиться → На экран «Домой»), затем включите уведомления в профиле.
- **Закрытое приложение:** уведомления не приходят, для этого нужен push-сервер (Web Push). Это можно добавить бесплатно через Supabase Edge Functions.

## Структура

```
index.html             разметка
style.css              оформление
app.js                 логика: вход, чаты, группы, каналы, аватарки, уведомления
sw.js                  service worker (уведомления, PWA)
manifest.webmanifest   настройки установки как приложения
icon.svg               иконка
config.example.js      пример конфигурации
schema.sql             таблицы и политики безопасности
migration_v2.sql       группы, каналы, аватарки, непрочитанные
```
